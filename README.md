# Still Snow

Бесплатный интерактивный снег для рабочего стола Mac. Приложение живёт в строке меню. Для снега интернет не нужен.

Готовый установщик доступен в [GitHub Releases](https://github.com/fqfqfqff/still-snow/releases/latest).

## Быстрый старт

1. Откройте DMG, перетащите Still Snow на значок Applications и откройте приложение из «Программы».
2. Нажмите на снежинку в строке меню. Здесь можно поставить снег на паузу, выбрать силу снегопада, ветер или инструмент.
3. Дайте снегу накопиться на верхнем краю окна. Проведите курсором по сугробу. Варежка сдвигает снег, лопата очищает область под курсором.
4. Для снеговика выберите «Лепить снеговика». Зажмите мышь на сугробе, перетащите шар к краю окна и отпустите. Следующий шар можно положить сверху. Пунктирное кольцо показывает, куда он встанет. Во время перетаскивания Esc отменяет лепку. Режим также выключается из меню и автоматически заканчивается после периода бездействия.
5. В «Настройках» отдельно выберите тему и иконку. Размер, прозрачность, оттенок снежинок и накопление можно изменить сразу. Язык можно выбрать там же. Доступны «Как в системе», «Русский» и «English». Для оформления доступны системный, светлый и тёмный режимы.

Выбранная иконка отображается в настройках. В строке меню используется монохромная снежинка macOS. У «Матового стекла» есть светлый и тёмный варианты. В Finder отображается светлая иконка, встроенная при сборке. В macOS 26+ на карточке предпросмотра используется Liquid Glass. На ранних версиях macOS там используется обычный материал.

## Поддержка

Эта тестовая сборка предназначена для Apple Silicon. Целевой минимум macOS 14. Сборка имеет локальную подпись ad hoc, без нотариализации Apple. Gatekeeper может ограничить запуск скачанной сборки. Самостоятельная сборка из этого репозитория доступна командами ниже.

Снежинки рисуются через AppKit/Core Graphics. Приложение читает геометрию видимых окон. Захват экрана не требуется. В сборках с настроенной лентой Sparkle подключается к серверу обновлений. Снег ложится на нижний Dock, когда macOS предоставляет его видимую рамку. При переключении Spaces и изменении конфигурации экранов снег сбрасывается. Перенос сугробов между мониторами пока не реализован.

## Обновления

В меню **Обновления** есть ручная проверка и два переключателя для фоновой проверки и установки. В сборке с опубликованной лентой оба включены по умолчанию. Sparkle проверяет EdDSA-подпись ленты и каждого архива обновления. Диалоги Sparkle используют язык macOS.

Для первой установки этой версии замените предыдущий Still Snow через DMG. Сборка без адреса ленты и публичного ключа показывает состояние «Источник обновлений не настроен». Инструкция подключения опубликованной ленты находится в [RELEASING.md](RELEASING.md).

## Сборка

Нужны macOS и Apple Command Line Tools с Swift 6.2 и SDK macOS 26 или новее. Сборка скачивает официальный Sparkle 2.10.1 с GitHub и проверяет SHA-256 и подпись фреймворка. После первого скачивания используется локальный кэш.

```sh
./scripts/test-macos.sh
./scripts/build-macos.sh
open "build/Still Snow.app"
```

`Sources/Snow.swift` содержит симуляцию без AppKit, `Sources/Desktop.swift` связывает её с оконной системой, `Sources/Settings.swift` содержит настройки SwiftUI. Настройки хранятся локально в UserDefaults. Скрипт `./scripts/package-macos.sh` собирает DMG со ссылкой на Applications.

Для публикации Windows и Linux потребуются отдельные оконные интеграции. Исходники текущей сборки предназначены для macOS.

## Quick start in English

Open the DMG and drag Still Snow to Applications. Open the app and click the snow icon in the macOS menu bar. Use **Settings** to switch the language, choose a theme and icon, or change the flakes. The download is an ad hoc signed, non-notarized Apple Silicon alpha.
