# Still Snow

Бесплатный интерактивный снег для рабочего стола Mac. Приложение живёт в строке меню. Для снега интернет не нужен.

Готовый установщик доступен в [GitHub Releases](https://github.com/fqfqfqff/still-snow/releases/latest).

## Быстрый старт

1. Откройте DMG, перетащите Still Snow на значок Applications и откройте приложение из «Программы».
2. Нажмите на снежинку в строке меню. В панели доступны пауза, сила снегопада, ветер, очистка, гирлянды, обновления и настройки.
3. Дайте снегу накопиться на верхнем краю окна. Проведите курсором, чтобы сдвинуть снег. Короткий клик по сугробу разбрасывает немного снега.
4. Для снеговика зажмите мышь на снегу, потяните шар и отпустите на краю окна или на другом шаре. Пунктирное кольцо показывает, куда он встанет. Esc отменяет перетаскивание.
5. На вкладке «Настройки» выберите тему, иконку, язык, размер, прозрачность и оттенок снега. Для оформления доступны системный, светлый и тёмный режимы.

Выбранная иконка отображается в настройках. В строке меню используется монохромная снежинка macOS. У «Матового стекла» есть светлый и тёмный варианты. В Finder отображается светлая иконка, встроенная при сборке. В macOS 26+ на карточке предпросмотра используется Liquid Glass. На ранних версиях macOS там используется обычный материал.

## Поддержка

Эта тестовая сборка предназначена для Apple Silicon. Целевой минимум macOS 14. Сборка имеет локальную подпись ad hoc, без нотариализации Apple. Gatekeeper может ограничить запуск скачанной сборки. Самостоятельная сборка из этого репозитория доступна командами ниже.

Снежинки рисуются через AppKit/Core Graphics. Приложение читает геометрию видимых окон. Захват экрана не требуется. В сборках с настроенной лентой Sparkle подключается к серверу обновлений. Снег ложится на нижний Dock, когда macOS предоставляет его видимую рамку. Сугробы на существующих окнах восстанавливаются после переключения Space. При смене геометрии дисплея слой пересоздаётся. Перенос сугробов между мониторами пока не реализован.

## Обновления

В разделе **Обновления** панели под снежинкой есть ручная проверка и два переключателя для фоновой проверки и установки. В сборке с опубликованной лентой оба включены по умолчанию. Sparkle проверяет EdDSA-подпись ленты и каждого архива обновления. Диалоги Sparkle используют язык macOS.

Если обновление недоступно, выйдите из Still Snow, перенесите приложение из DMG в «Программы» через Finder и откройте эту копию. Запуск из образа или из App Translocation оставляет приложение только для чтения. Сборка без адреса ленты и публичного ключа показывает состояние «Источник обновлений не настроен». Инструкция подключения опубликованной ленты находится в [RELEASING.md](RELEASING.md).

## Сборка

Нужны macOS и Apple Command Line Tools с Swift 6.2 и SDK macOS 26 или новее. Сборка скачивает официальный Sparkle 2.10.1 с GitHub и проверяет SHA-256 и подпись фреймворка. После первого скачивания используется локальный кэш.

```sh
./scripts/test-macos.sh
./scripts/build-macos.sh
open "build/Still Snow.app"
```

`Sources/Snow.swift` содержит симуляцию без AppKit, `Sources/Desktop.swift` связывает её с оконной системой, `Sources/Settings.swift` содержит настройки SwiftUI. Настройки хранятся локально в UserDefaults. Скрипт `./scripts/package-macos.sh` собирает DMG со ссылкой на Applications.

Для публикации Windows и Linux потребуются отдельные оконные интеграции. Исходники текущей сборки предназначены для macOS.

## Quick start in English

Open the DMG and drag Still Snow to Applications. Open the app and click the snow icon in the macOS menu bar. The menu-bar panel contains snowfall controls, garlands, updates, and Settings. Sweep snow with the pointer or drag from a drift to roll a snowball. The download is an ad hoc signed, non-notarized Apple Silicon alpha.
